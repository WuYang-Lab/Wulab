Overview

About

The Genome-wide Bayesian Mixture Model (GBMM) implemented in GCTB (e.g. SBayesRC) performs genome-wide fine-mapping (GWFM) by modelling the joint effects of all SNPs across the genome, rather than one locus at a time. It requires GWAS summary statistics and linkage disequilibrium (LD) data from a reference sample, and can incorporate functional annotations as priors.

Because GWFM accounts for the global genetic architecture instead of a single region, it improves error control, mapping power, resolution and replication rate over locus-based fine-mapping. In the accompanying paper, credible sets across 48 complex traits explained 18% of SNP-based heritability on average, with 30% of them located outside genome-wide significant loci.

What you need

  • GWAS summary statistics in GCTA format — one row per SNP, with allele frequency, effect, SE, P value and sample size.
  • Reference LD — we provide block-wise full LD matrices for 13 million SNPs from 10,000 unrelated UK Biobank participants of European ancestry (see Download).
  • Annotation file (optional) — per-SNP functional annotations used as priors, e.g. 96 baseline annotations.
  • Gene map (optional) — used to report the nearest gene for each credible set.

Installation

GWFM is a module of GCTB, and needs version 2.0 or above. Download the pre-compiled executable for Linux, macOS or Windows from the GCTB download page, or compile it from the source archive provided there. After installing, run gctb --help to list the available modules and confirm that GWFM is available in your build.

Tutorial

GWFM runs in two steps: eigen-decomposition of the reference LD, then the genome-wide Bayesian mixture model. Credible sets are produced along with the model and can be recomputed later with different thresholds.

Prepare the input

GWAS summary statistics must be in GCTA format, one line per SNP, with these columns in this order:

SNP A1 A2 freq b se p N
rs1001 A G 0.8493 0.0024 0.0055 0.6653 129850
rs1002 C G 0.0306 0.0034 0.0115 0.7659 129799
rs1003 A C 0.5128 0.0045 0.0038 0.2319 129830

SNP SNP identifier, matching the IDs in the reference LD matrices.

A1 A2 effect allele and the other allele.

freq frequency of A1; b and se the effect size and its standard error.

p P value; N sample size.

Step 1. Generate eigen-decomposition data

Compute the eigen-decomposition for every LD block using multiple threads:

gctb --ldm ukbEUR_13M_FullLDM --gwas-summary test.ma \
     --make-ldm-eigen --thread 32 --out matched_ldm

--ldm folder containing the block-wise full LD matrices, unzipped from ukbEUR_13M_FullLDM.zip.

--gwas-summary the GWAS summary statistics file described above; only SNPs present in both files are kept.

--make-ldm-eigen --thread compute the eigen-decomposition for all blocks, using the given number of threads.

--out output folder that stores the eigen-decomposition data for the matched SNPs.

On an HPC cluster it is usually faster to compute the blocks in parallel, one job per block:

gctb --ldm ukbEUR_13M_FullLDM --gwas-summary test.ma \
     --make-ldm-eigen --block $i --out matched_ldm

--block run a single block, where i is the block index starting from 1.

Step 2. Run genome-wide fine-mapping

gctb --gwfm RC --ldm-eigen matched_ldm --gwas-summary test.ma \
     --annot annot.txt --gene-map gene_map.txt \
     --thread 32 --out test

--gwfm the fine-mapping method, e.g. RC for SBayesRC.

--ldm-eigen the eigen-decomposition data generated in Step 1.

--annot the annotation file: SNP ID, an Intercept column of ones, then one column per annotation. Any number of annotations can be included.

--gene-map gene map file used to annotate the nearest gene of each credible set. This flag is optional.

--genome-build genome build of the gene map, hg19 or hg38; hg19 is used by default.

--thread number of threads. We recommend 32 (or any multiple of 4), because 4 MCMC chains are run in parallel by default.

--out prefix for the result files described below.

The annotation file has this layout:

SNP     Intercept   Anno1   Anno2   Anno3
rs1001  1           1       0       0.2
rs1002  1           0       1       -1.5
rs1003  1           1       1       0.7

And the gene map, which carries both builds in one file:

Columns are the SNP index, name, chromosome, position, effect allele, other allele, effect-allele frequency, posterior effect size, its standard error, posterior SNP-based heritability enrichment probability (PEP), posterior inclusion probability (PIP), and Gelman & Rubin R for convergence assessment.

Other model estimates

test.parRes genetic architecture estimates. test.parSetRes annotation-specific parameter estimates. test.enrich per-SNP heritability enrichment in each annotation.

test.mcmcsamples MCMC samples of SNP effects in binary format, needed to recompute credible sets in Step 3.

test.skepticalSNPs SNPs whose joint effects were set to zero, because their effects are likely inflated by poor data quality or large LD mismatch between the GWAS and the reference sample.

Step 3. (Re)calculate credible sets

Local credible sets (LCS) are constructed with a PIP threshold of 0.9 and a PEP threshold of 0.7 by default. To recompute them with other thresholds:

gctb --cs --pwld-file ldm/rsq0.5.pwld --pip 0.9 --pep 0.7 \
     --gene-map gene_map.txt --flank 5000 --genome-build hg19 \
     --mcmc-samples test --out test

--cs calculate local and global credible sets.

--pip coverage threshold of the credible set.

--pep threshold on the posterior enrichment probability.

--flank flanking window used to define the nearest gene; 5,000 bp by default.

--genome-build genome build of the gene map, hg19 or hg38.

--mcmc-samples MCMC samples written by the fine-mapping step.

--out writes the four credible-set files described below.

--pwld-file LD file holding pairwise r2 > 0.5 between SNPs within each block.

The pairwise LD file is shipped in the ldm folder. To build it from the eigen-decomposition reference:

gctb --get-pwld --ldm-eigen ldm --rsq 0.5 --thread 8 --out rsq0.5

--get-pwld compute a pairwise LD file from the eigen-decomposition reference.

--rsq the r2 threshold above which a SNP pair is written out.
